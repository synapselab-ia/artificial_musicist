## Selected architecture — A: CHAIN OF CUSTODY

Dramatic principle: **trace how one sentence gets altered at every handoff**.

Structure:

`CHOPPED COLD OPEN -> VALE / ORIGINAL STATEMENT -> ELIAN PRE-CHORUS -> CHORUS 1 / MISQUOTED VERSION -> ROOK / CHAIN-OF-CUSTODY RAP -> MIRO / RECONSTRUCTION -> NOEN / CLEAN CORRECTION -> CHORUS 2 / TAKE IT WHOLE -> SHORT BRIDGE / NO EDITS -> FINAL CHORUS / FULL CONTEXT -> EON + GROUP OUTRO TAG`

How it works:

The opening establishes one clear thought, then the first chorus deliberately presents a distorted or incomplete version of it. ROOK dissects the path from original line to reposted fragment in the song's densest technical block. MIRO begins putting the meaning back together. NOEN finally gets a stripped, uninterrupted correction with almost no production interference. The last third then stops chopping the lead vocal and allows the complete statement to land.

Seven-member map:

- VALE: original low-register statement and measured rebuttal;
- ELIAN: melodic setup into the first hook;
- SOREN: main chorus identity;
- ROOK: longest and most technical rap centerpiece;
- MIRO: reconstruction block between rap and melody;
- NOEN: exposed truth/correction block;
- EON: late counterline and final upper-register expansion.

Why selected:

- clearest narrative mechanism for the concept;
- lets rap carry evidence and transformation rather than functioning as a token verse;
- gives all seven members distinct dramatic jobs;
- supports the `RECEIPT TAPE` production language without requiring excessive section switching;
- naturally creates a transformed final chorus where context is restored instead of merely repeating the first hook.

## Duration discipline

The architecture is authored around an essential-song budget of approximately **2:45–2:50**.

Later Flow-facing generation should normally request approximately **2:55–2:58**, require a complete clean ending by approximately **2:59**, and never intentionally exceed **3:00**.

The margin is reserved for complete rap diction, breathing, transitions, and ending decay — not extra choruses, dance breaks, solos, long intros/outros, or filler repetitions.
