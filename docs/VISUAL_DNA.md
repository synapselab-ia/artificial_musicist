# VISUAL DNA

Status: **FOUNDATION — MASTER REFERENCES PENDING**

## Goal

Create seven recognizable fictional members who remain visually consistent across eras while allowing normal K-pop styling changes.

## Canonical visual strategy

Each approved member should eventually have a master reference set containing:

- neutral front portrait;
- three-quarter portrait;
- side profile;
- full-body reference;
- neutral expression;
- performance expression;
- written facial and body descriptors;
- stable identifying features;
- baseline hairstyle and styling notes.

## What may change by era

- hair color and styling;
- makeup;
- wardrobe;
- accessories;
- lighting;
- set design;
- photographic treatment;
- concept-specific styling.

## What should remain recognizable

- facial structure;
- eye shape and placement;
- nose and mouth proportions;
- core complexion range;
- body proportions;
- stable identifying details;
- member ID.

## Flow visual principle

When a release uses visual references, preserve the established fictional characters rather than generating a new anonymous seven-member cast.

## Debut visual world

`Last Train Home` uses a cinematic late-night train-station concept with restrained, realistic high-end music-video cinematography, cool desaturated tones, selective warm highlights, reflective surfaces, empty-platform imagery, and an unresolved departure motif.

This is the debut era's visual language, not the permanent visual style of every comeback.
