# VISUAL DNA

Status: **F3 IN PROGRESS — GROUP-LEVEL VISUAL BASELINE APPROVED / MASTER REFERENCES PENDING**

## Goal

Create seven recognizable fictional members who remain visually consistent across eras while allowing normal K-pop styling changes.

## Canonical group-level visual baseline

UNFRAME should read immediately as a **fictional contemporary Korean male K-pop idol group** with polished, mainstream, top-tier idol visuals.

The visual target combines:

- clearly Korean / East Asian male facial identity;
- contemporary mainstream K-pop beauty standards;
- conventionally attractive, polished idol presentation across all seven members;
- clean grooming and refined skin presentation while retaining believable skin texture;
- slim-to-athletic stage-ready physiques rather than bulky builds;
- premium editorial and luxury-fashion sensibility;
- a lightly globalized / westernized high-fashion presentation without erasing Korean facial identity;
- individual facial differentiation strong enough that the members remain recognizable even with similar hair, wardrobe, and lighting.

Real K-pop artists may be used only as a broad reference for production value, polish, and mainstream idol appeal. Do not intentionally reproduce the face, signature styling, or recognizable likeness of any real person.

## Differentiation rule

All seven members should satisfy the same high beauty bar without becoming clones. Their distinction should come from facial geometry, eye shape and spacing, brow structure, nose and mouth proportions, jawline, stable identifying details, body proportions, expression, and performance aura.

A useful stress test is whether the seven remain distinguishable if all are shown with black hair, simple dark clothing, neutral studio lighting, and the same background.

## Canonical visual strategy

Each approved member should eventually have a master reference set containing:

- neutral front portrait;
- three-quarter portrait;
- side profile;
- full-body reference;
- neutral expression;
- performance expression;
- written facial and body descriptors;
- stable identifying features;
- baseline hairstyle and styling notes.

## What may change by era

- hair color and styling;
- makeup;
- wardrobe;
- accessories;
- lighting;
- set design;
- photographic treatment;
- concept-specific styling.

## What should remain recognizable

- facial structure;
- eye shape and placement;
- eyebrow structure;
- nose and mouth proportions;
- jawline and cheek structure;
- core complexion range;
- body proportions;
- stable identifying details;
- member ID.

## Master-reference generation principle

Build the members **one at a time**, beginning with a clean neutral studio master portrait. Do not begin with seven-member group images or concept-heavy scenes.

For each member:

1. establish and approve the neutral front master portrait;
2. generate a three-quarter view using the approved face as reference;
3. generate a side profile using the same identity;
4. generate a neutral full-body reference;
5. generate one controlled performance-expression reference;
6. only then freeze the member's visual identity as canon.

If a face is not strong enough in the neutral portrait, revise it before generating the rest of the reference set.

## Google generation workflow

Google image-generation tools are the preferred external generation environment for F3 because the user prefers their photorealistic character output. GitHub remains the canonical source for prompts, approved traits, filenames, and decision history.

Generated images do not become canonical merely because they were produced. Canon requires explicit user approval.

## Flow visual principle

When a release uses visual references, preserve the established fictional characters rather than generating a new anonymous seven-member cast.

## Debut visual world

`Last Train Home` uses a cinematic late-night train-station concept with restrained, realistic high-end music-video cinematography, cool desaturated tones, selective warm highlights, reflective surfaces, empty-platform imagery, and an unresolved departure motif.

This is the debut era's visual language, not the permanent visual style of every comeback.
